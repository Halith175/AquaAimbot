Aqua Aimbot Android project
============================

Package: com.halith.aquaimbot

The game is a local WebView app. It contains:
- Touch fish target selection
- Target highlight
- Shoot button
- Score system
- Moving fish
- Android portrait layout

Build:
1. Open this project in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).
4. Install the generated APK on Android.

This project does not require internet at runtime.
